## Хронология Ключевых Событий

### 2026-04-21 — Стабилизация Фазы 0
- **Событие:** Pith v5 запущен как systemd-сервис (`pith-telegram`).
- **Урок:** Использование `EnvironmentFile` в systemd обязательно для загрузки `.env`.
- **Связанные артефакты:** `/etc/systemd/system/pith-telegram.service`

- **Событие:** Исправлена ошибка `no such column: metadata_json` в БД.
- **Урок:** Все миграции схемы БД должны выполняться до запуска сервисов.
- **SQL:** `ALTER TABLE episodes ADD COLUMN metadata_json TEXT;`

- **Событие:** Код `telegram_bot.py` восстановлен из бэкапа `telegram_bot.py.bak.2026-04-21_08-42-23`.
- **Урок:** Всегда держать актуальный бэкап перед правками. Использовать `git` (TODO).

- **Событие:** Cron-задача для `nightly_evolution.py` исправлена: добавлена загрузка `.env`.
- **Урок:** Cron не наследует окружение пользователя. Всегда использовать `set -a; source .env; set +a`.

- **Событие:** Устранена ошибка `slice(None, 50, None)` в боте.
- **Причина:** `planner.think()` возвращал словарь, а не строку.
- **Решение:** Добавлена функция `safe_str()` для унификации обработки ответов.

- **Событие:** Оркестратор (`orchestrator.run()`) временно отключен из-за отсутствия методов.
- **План:** Вернуться к оркестратору в Фазе 3 (Cognition Graph).
